# 🇫🇷 Guide général
## Roaming GitHub
- « se promener librement ».
- Lecture en ligne : Guide de Roaming GitHub  
- Téléchargements : markdown

### 🚀 Pourquoi “se promener” sur GitHub
- GitHub n’est pas seulement un hébergeur de code.  
- C’est un écosystème vivant, un réseau social de développeurs, un laboratoire d’idées, un musée de projets, un terrain de jeu open-source.

### 🚀 Se promener librement sur GitHub
- découvrir des projets inspirants  
- comprendre comment les autres codent  
- apprendre en observant  
- contribuer quand tu veux  
- construire ton propre espace numérique  

---

### 🧭 1. Explorer les dépôts comme des paysages
>Chaque dépôt GitHub est un lieu
- Le README.md est l’enseigne du lieu  
- Les dossiers sont les chemins  
- Les issues sont les discussions du village  
- Les pull requests sont les portes d’entrée pour contribuer  
- Les releases sont les versions historiques du lieu

### 🔍 2. Utiliser la recherche
>GitHub propose une recherche extrêmement puissante :
- par langage  
- par popularité  
- par date  
- par sujet (topics)  
- par organisation  
- par fichier spécifique  

Tu peux littéralement trouver n’importe quel type de projet, du plus simple au plus avancé.

---

### 🧑‍💻 3. Suivre les développeurs comme des explorateurs
>GitHub permet de :
- suivre des utilisateurs  
- suivre des organisations  
- suivre des dépôts  
- recevoir des notifications ciblées  

Tu peux ainsi observer les pratiques, les styles de code, les workflows, les architectures.

---

### 🗺️ 4. Construire ton propre territoire
- Ton profil GitHub est ton pays numérique.
>Tu peux y afficher :
- tes projets  
- tes contributions  
- ton activité  
- ton identité visuelle  
- ton GitHub Pages (ton site web personnel)

### 🏗️ 5. GitHub Pages : ton refuge personnel
- GitHub Pages te permet de créer un site web gratuit, directement depuis un dépôt.
>Idéal pour :
- documenter un projet  
- créer un wiki  
- publier un portfolio  
- héberger un guide comme celui‑ci  
- présenter ton écosystème de projets
